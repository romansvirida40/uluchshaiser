# Uluchshaizer

Плагин коррекции высоты вокала в реальном времени (VST3 / AU / Standalone), JUCE 8.0.15, C++17.
По логике работы ориентирован на Auto-Tune Artist / MetaTune / FedaTune. Интерфейс, код и DSP свои.

## Что реализовано

| Блок | Как работает на самом деле |
|---|---|
| **Pitch detection** | YIN по прореженному (≥8 кГц) сигналу с антиалиасингом, затем уточнение лага на полной частоте и параболическая интерполяция (точность до долей цента). Против октавных ошибок: правило «первого провала» YIN, проверка непрерывности октавы, медианный фильтр. Тишина и шумные (глухие) участки помечаются и не корректируются. |
| **Pitch correction** | Ближайшая *разрешённая* нота (12-битная маска), гистерезис против дребезга между нотами. |
| **Pitch shifting** | TD-PSOLA: формант сохраняется по построению, поэтому нет эффекта «Буратино». |
| **Formant** | Независимо от высоты: каждый грейн PSOLA ресемплируется, огибающая спектра сдвигается до ±5 полутонов при ±100 %. |
| **Doubles** | Два дополнительных голоса PSOLA из того же анализа. У каждого свой медленно плавающий детюн (+9 / −11 центов), сдвиг форманты и задержка 11 / 19 мс ±2 мс. |
| **Width** | Панорама дублей с постоянной мощностью (0 % = центр, 100 % = крайние L/R). |
| **Double Dry/Wet** | Баланс основного голоса и дублей: 0 % только лид, 50 % оба на полной громкости, 100 % только дубли. |
| **Volume** | 0–100 %. 80 % = 0 dB, 100 % = +3,9 dB. Мягкий лимитер-клиппер на выходе, пик ≤ 0 dBFS. |
| **Low Latency** | Короче окно YIN, чаще анализ, меньше look-ahead PSOLA. Задержка вдвое ниже, сообщается хосту (PDC). |
| **Input Type** | Меняет диапазон поиска F0, порог YIN, гистерезис, медиану и, как следствие, задержку. |

### Параметры коррекции

- **Retune Speed (−3.0 … 100)**: больше значение = быстрее коррекция. Это постоянная времени сглаживания поправки: τ = 600 мс · (1.5/600)^((v+3)/103).
  - −3 → 600 мс (очень мягко)
  - 0 → 504 мс
  - 32.7 → 75 мс
  - 80 → 4.5 мс
  - 100 → 0 мс (мгновенно, классический hard-tune)
- **Sustain (0–100 %)** — коррекция, зависящая от длины ноты (как Humanize). Пока нота держится меньше ~80 мс, работает заданная скорость. Дальше (полностью к ~400 мс) коррекция плавно замедляется: τ += Sustain · (3τ + 120 мс). Короткие ноты остаются точными, а длинные сохраняют живое вибрато.
- **Amount (0–100 %)**: какую долю вычисленной поправки применять. 0 % значит без коррекции, сигнал проходит без изменений.
- **Flex Tune (0–100 %)**: вес коррекции падает с расстоянием до целевой ноты. При 0 исправляется всё. При больших значениях исправляются только ноты, к которым певец уже близок, а намеренные подтяжки и украшения проходят как есть. Внешняя граница зоны: 1.0 → 0.2 полутона.
- **Pitch (−12 … +12 st)**: ручной сдвиг высоты, форманты сохраняются.
- **Key / Scale**:
  - 12 тоник, Major, Minor (натуральный), Chromatic.
  - 12 переключателей нот: смена тональности перезаписывает их по ладу, после этого можно править вручную (правый клик или Shift-клик по кружку, либо клик по клавише в Piano Mode).
  - Выключенные ноты никогда не становятся целью.
  - Названия нот зависят от тональности: Eb minor, Ab major, F# minor.
  - Новые лады добавляются в `Source/dsp/Scales.h` (одна строка таблицы).

### Задержка (48 кГц)

| Input Type | Обычный режим | Low Latency |
|---|---|---|
| Soprano | 20.0 мс | 10.0 мс |
| Alto / Tenor | 31.6 мс | 15.8 мс |
| Low Male | 46.2 мс | 23.1 мс |
| Instrument | 50.0 мс | 25.0 мс |
| Bass Instrument | 100 мс | 50 мс |

Задержка сообщается хосту, FL Studio и другие DAW компенсируют её автоматически.

### Интерфейс

- Сфера Retune Speed: стеклянный орб, который просчитывается попиксельно. Внутри объёмная кристаллическая структура (сферическая диаграмма Вороного), видная сквозь переднюю и заднюю стенки. Свет поднимается как жидкость по мере роста Retune Speed. Есть френелевская подсветка края, искры и парящие частицы. Работает как вертикальный драг:
  - вверх увеличивает значение, Shift даёт тонкую подстройку;
  - двойной клик сбрасывает значение, колесо мыши тоже работает;
  - клик по числу под сферой открывает пресеты скорости.
- Все ручки: драг, Shift-драг, колесо, двойной клик для сброса.
- Input Type: анимированный выпадающий список, закрывается кликом мимо.
- Piano Mode: кнопка-клавиатура или шеврон слева снизу. Панели плавно поднимаются, клавиатура выезжает снизу. Раскладка как на референсном фото, Double Dry/Wet и Doubles Width остаются видимыми. Голубая точка на клавише показывает текущую распознанную ноту.
- Панель Vocal: полосы показывают реальный пиковый уровень входа, нота берётся из детектора. Без сигнала идёт тихая idle-анимация.
- Пресеты: 9 заводских плюс пользовательские (`Документы/Uluchshaizer/Presets/*.ulzpreset`). Пресеты не меняют тональность, лад и ноты.
- Фон: шёлковые светящиеся ленты, анимированы только в левой половине. Панели из тёмного стекла кэшируются, поэтому анимация дёшевая: сфера 30 fps, фон 24 fps.
- Окно масштабируется (800×450 … 1920×1080).
- Учитывается системная настройка «уменьшить движение» (Windows и macOS).

## Сборка

Нужны CMake ≥ 3.22 и компилятор C++17. JUCE 8.0.15 скачивается автоматически, либо можно указать `-DJUCE_DIR=путь`.

**Windows (Visual Studio 2022):**
```
cmake -B build -G "Visual Studio 17 2022"
cmake --build build --config Release --target Uluchshaizer_VST3 Uluchshaizer_Standalone
```
Плагин: `build\Uluchshaizer_artefacts\Release\VST3\Uluchshaizer.vst3`. Скопируйте его в `C:\Program Files\Common Files\VST3\`.

**macOS (Xcode CLT):**
```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target Uluchshaizer_VST3 Uluchshaizer_AU Uluchshaizer_Standalone
```
Получится Universal (arm64 + x86_64). Куда копировать:
- `Uluchshaizer.vst3` → `~/Library/Audio/Plug-Ins/VST3/`
- `Uluchshaizer.component` → `~/Library/Audio/Plug-Ins/Components/`

Если macOS блокирует файл, выполните `xattr -dr com.apple.quarantine <путь>`.

**Без локальной сборки.** Залейте папку в репозиторий GitHub. Workflow `.github/workflows/build.yml` соберёт версии для Windows и macOS, прогонит DSP-тесты и выложит готовые плагины в Artifacts.

## Проверка в FL Studio

1. Options → Manage plugins → **Find installed plugins** (или добавьте путь к папке VST3).
2. Поставьте Uluchshaizer в слот микшера на дорожке с вокалом.
3. Задайте тональность песни (тоника + Major/Minor) и Input Type под голос.
4. Для «роботизированного» эффекта: Retune 100, Sustain 0, Flex 0. Для естественной правки: Retune 15–35, Sustain 50–80, Flex 40–60.
5. Для записи в реальном времени включите Low Latency.
6. Задержка компенсируется автоматически. Автоматизируются все 25 параметров (через Browse parameters / Last tweaked).

## Тесты

- `UluchshaizerDspTest`: офлайн-проверка DSP на синтетическом голосе (глоттальный источник, 3 форманты, вибрато, фальшивые ноты, согласные). WAV-файлы пишутся в указанную папку.
- `UluchshaizerHostTest <Uluchshaizer.vst3> <in.wav> <out.wav>`: грузит собранный VST3 как DAW, обрабатывает файл и проверяет параметры, задержку, Low Latency и Input Type, восстановление состояния, лады и редактор.
- `UluchshaizerUiSnapshot <voice.wav> <dir>`: снимки реального редактора, пока реальный процессор обрабатывает звук.
